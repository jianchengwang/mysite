A Better Wrong Turn｜走错一步，也能有好体验

今天换到科技与设计。Renny Gleeson 的 TED 演讲《404, the story of a page not found》，3分50秒，讨论网页出错后怎样回应用户。

下面四段是原创学习稿，人物和情节为学习示例，不是 TED 原文或全文翻译。加粗语块可以整块记。

On Monday morning, Lin opens an old link to a design guide. She is **looking for** a simple answer, but she **runs into** an error page. There is a number in the middle of the screen and nothing else. She closes the tab.

星期一早上，Lin 打开一个通往设计指南的旧链接。她正在**寻找**一个简单的答案，却**遇到了**错误页面。屏幕中央只有一个数字，除此之外什么也没有。她关掉了标签页。

Later, Lin works on an error page for her own website. **Instead of** showing only a code, she writes a short explanation. She adds a search box and a clear link to the home page. Now visitors have somewhere to go.

后来，Lin 开始设计自己网站的错误页面。她写了一句简短说明，**而不是**只显示一个代码。她加上搜索框，以及一个清晰的首页链接。现在，访客知道可以去哪里了。

She asks a friend to test the page. He understands the message, but the first button takes him to the wrong place. Lin fixes the link and tests it again. A friendly message is useful only if it helps people **get back to** their task.

她请朋友测试这个页面。他看懂了提示，但第一个按钮却把他带到了错误的位置。Lin 修好链接，又测试了一遍。友好的提示要能帮助人们**回到**原来的任务，才真正有用。

By the end of the day, Lin sees the problem differently. She cannot prevent every broken link, but she can offer a useful next step. With a little care, she can **turn a frustrating moment into** a helpful one.

到当天结束时，Lin 对这个问题有了不同的理解。她无法避免每个失效链接，但可以提供一个有用的下一步。多用一点心，她就能**把让人沮丧的时刻变成**能帮上忙的时刻。

五个常用表达，例句均为原创：

1. **look for** /lʊk fɔːr/：寻找。句中 for 可弱读 /fər/。
I’m looking for a clearer example.
我正在找一个更清楚的例子。

2. **run into** /rʌn ˈɪntuː/：遇到。run‿into 顺接，不逐词停顿。
We ran into a problem during the test.
我们在测试时遇到了问题。

3. **instead of** /ɪnˈsted əv/：而不是；代替。重读 STED，of 轻读。
Try a shorter sentence instead of a long explanation.
试试用一个短句，代替长篇解释。

4. **get back to** /ɡet bæk tə/：回到；重新开始做。重读 BACK，to 轻读。
Let’s get back to the main question.
我们回到主要问题上来吧。

5. **turn A into B**：把 A 变成 B。turn /tɜːrn/；into /ˈɪntuː/。
We turned an empty room into a small library.
我们把一间空房变成了小图书馆。

两分钟跟读：
官方原声约 3:18–3:25，已按官方字幕核对：
“This is an error page, but what if this error page was also an opportunity?”
这是一个错误页面，但如果它同时也是一次机会呢？

先听一次，再暂停模仿，最后跟着原声说。突出 ERROR PAGE 和 opportunity 的主重音 /ˌɑːpərˈtuːnəti/ 中的 TU，不刻意拖慢每个词。404 常读 four-oh-four。

再读一句原创练习：
We can turn a problem / into a useful lesson.
我们可以把一个问题，变成一次有用的学习机会。

一分钟复述：
What did Lin change on her error page, and how did those changes help visitors?
Lin 修改了错误页面的哪些地方？怎样帮助了访客？
用三句回答：At first, Lin… / Then, she… / This helped visitors…
尽量用上 instead of 和 get back to。
